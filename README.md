# 多目标跳频信号定位系统

基于信道化滤波的多目标跳频信号检测、分选与定位系统

## 项目简介

本项目实现了一个完整的多目标跳频信号定位系统，能够同时处理多个跳频辐射源的信号，并通过多观测站接收数据进行目标定位。主要功能包括：

- 多目标跳频信号生成与仿真
- 基于信道化滤波的信号检测
- 多辐射源信号分选
- TDOA（时差定位）算法
- 脉冲特征提取与分析

## 系统特性

- ✅ 支持多目标（2-5个）跳频信号处理
- ✅ 20信道信道化滤波器组
- ✅ 自适应能量检测算法
- ✅ 基于DBSCAN的信号分选
- ✅ 多站TDOA定位
- ✅ CIC滤波器优化
- ✅ 完整的可视化分析

## 系统架构

```
跳频信号生成 → 多站接收 → 信道化滤波 → 能量检测 → 信号分选 → 特征提取 → TDOA定位
```

## 主要文件说明

- `multi_target_signal_sorting.m` - 多目标信号分选主函数
- `generate_multi_target_signals.m` - 多目标信号生成
- `extract_pulse_features.m` - 脉冲特征提取

### 完整示例

- `hop_freq_dpd_2_40m_5_targets_add_hop_cic.m` - 完整的多目标跳频定位仿真（包含CIC滤波器）

## 快速开始

### 环境要求

- MATLAB R2018b 或更高版本
- 信号处理工具箱 (Signal Processing Toolbox)
- 通信工具箱 (Communications Toolbox)

### 运行示例

1. 克隆或下载本项目到本地
2. 在MATLAB中打开项目目录
3. 运行主程序：

```matlab
% 运行完整的多目标定位仿真
run('20251113/hop_freq_dpd_2_40m_5_targets_add_hop_cic.m')
```

### 参数配置

主要参数在脚本开头设置：

```matlab
T_hop = 10e-3;          % 每跳持续时间 10ms
SymbolRate = 50e3;      % 符号速率 50k Baud
Modulation = 'QPSK';    % 调制方式
NumTargets = 2;         % 目标数量
NumChannels = 20;       % 信道数
```

## 系统工作流程

### 1. 信号生成模块
生成多个目标的跳频信号，每个目标具有：
- 独立的跳频图案
- 可配置的信号功率
- 不同的符号速率

### 2. 信道化滤波模块
- 20路信道化滤波器组
- 320kHz信道带宽
- CIC滤波器优化

### 3. 能量检测模块
- 自适应阈值检测
- 基于噪声功率估计
- 虚警率控制

### 4. 信号分选模块
- 多维特征提取（时间、频率、幅度、DOA、带宽）
- DBSCAN聚类算法
- 辐射源识别与分离

### 5. TDOA定位模块
- 多站时差测量
- GCC-PHAT时延估计
- 最小二乘定位算法

## 算法说明

### 信道化滤波

采用多相滤波器组实现高效信道化：
- 基于FFT的快速实现
- 低复杂度、高实时性
- 良好的频率分辨率

### 信号分选

基于DBSCAN的多维特征聚类：
- 时间-频率特征
- 幅度特征
- DOA（到达角）特征
- 带宽特征

### TDOA定位

经典的时差定位算法：
- GCC-PHAT时延估计
- 多站联合定位
- 迭代最小二乘优化
